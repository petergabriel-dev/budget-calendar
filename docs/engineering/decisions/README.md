# Decisions

| ADR | Status | Summary | Read when |
|---|---|---|---|
| [ADR-0001](ADR-0001-computed-account-balance-from-ledger.md) | Active | Compute account balance from `initial_balance + SUM(signed_amount)` over confirmed ledger rows; no mutable balance total. | Changing balance, STS, net-worth, projection, transaction sign, or account/budget SQL. |
| [ADR-0002](ADR-0002-reactive-cross-repository-invalidation.md) | Active | Transaction writes emit `transactionChangedTrigger`; dependent repos use `flatMapLatest` to force fresh SQLDelight queries. | Adding transaction mutators, repository flows, or transaction-dependent queries. |
| [ADR-0003](ADR-0003-single-compose-ui-android-ios.md) | Active | Android and iOS share one Compose UI; iOS SwiftUI is only a thin host for `MainViewController()`. | Adding screens, navigation, feature UI, or iOS app entrypoints. |
| [ADR-0004](ADR-0004-retire-specs-and-pencil.md) | Active | Retire the legacy spec tree, shadow specs, command-driven spec workflow, and external design-app loop; use `docs/engineering/`, source code, and `design-system.html` as truth. | Changing repo planning workflow, agent instructions, or design-system source-of-truth policy. |
| [ADR-0005](ADR-0005-retire-is-sandbox-flag.md) | Active | Retire main-table `transactions.is_sandbox`; sandbox transactions live only in `sandbox_snapshots` and `sandbox_transactions`. | Changing sandbox storage, simulation transaction rows, balance/budget/credit-card SQL, or any sandbox flag proposal. |
| [ADR-0006](ADR-0006-credit-card-liability-balance-reservation.md) | Active | Credit-card STS reserve is projected unpaid balance from each card's liability ledger, clamped per card; card charges stay out of overdue lifecycle. | Changing STS, credit-card reserve/payment flows, overdue marking, statement automation, or `signed_amount` semantics. |
| [ADR-0007](ADR-0007-card-aware-transaction-sheet-over-limit-block.md) | Active | Transaction sheet treats credit-card expenses as card charges, suppresses cash insufficient-funds warnings, and hard-blocks over-limit charges when a limit is set. | Changing add/edit transaction sheet validation, card available-credit UI, credit-card summaries, or warn-only vs hard-block policy. |
| [ADR-0008](ADR-0008-unified-projected-credit-card-balance.md) | Active | Credit-card displayed balance is signed projected balance, unified across Accounts, detail sheet, available credit, and net worth while STS reserve remains ADR-0006. | Changing credit-card summary/list/detail UI, net-worth, projected card SQL, or transaction-reactive summary flows. |
| [ADR-0009](ADR-0009-card-native-charge-sheet-statement-cycle.md) | Active | Card-selected transaction sheet becomes a charge form with Posted status and display-only statement-cycle dates; settings use recurring closing/due days while ledger/STS math stays unchanged. | Changing card transaction sheet behavior, statement-cycle settings/display, retired manual statement fields, or statement automation. |
| [ADR-0010](ADR-0010-credit-cards-as-accounts.md) | Active | Credit cards are account tiles led by available credit, with live display-only statement due, mandatory inline setup, and exclusive closing boundary while STS/net-worth math stays unchanged. | Changing Accounts credit-card tile, statement due, card setup requirements, cycle boundary, available-credit UI, STS, net-worth, or statement automation. |
| [ADR-0011](ADR-0011-fixed-six-row-calendar-grid.md) | Active | Calendar always renders 42 cells in six weighted rows sized from leftover space, with no lazy scroll state or fixed cell-height constant. | Changing calendar month construction, grid layout, cell sizing, scrolling, or vertical allocation. |
| [ADR-0012](ADR-0012-modal-picker-as-single-select-paradigm.md) | Active | Use modal pickers for form selects: `BcOptionPickerModal` for label lists and `AccountPickerModal` for account context; action overflow menus remain separate. | Adding form selects, changing picker components, account picker context, or nested modal-sheet behavior. |
